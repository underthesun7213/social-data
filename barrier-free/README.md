# 배리어 프리(Barrier-Free) 국가 비교 데이터

7개 지역 리서치 결과를 합친 데이터셋이다. 수집 기준과 등급 정의는 [SPEC.md](SPEC.md)를 따른다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `SPEC.md` | 평가 차원(LAW·TRANS·BUILT·DIGI·EMP·TOUR·DATA), 상/중/하 기준, 파일 형식 |
| `regions/<지역>.md` | 지역별 서술형 리포트(국가 개요, 우수·문제 사례, 데이터 공백) |
| `regions/<지역>_indicators.csv` / `_ratings.csv` | 지역별 원자료 |
| `all_ratings.csv` | 전체 등급 통합본 (47개국 + 미국 주·도시 15곳), ISO3 코드·평가된 차원 수·평균 점수(상3/중2/하1) 포함 |
| `all_indicators.csv` | 전체 지표 통합본, ISO3 코드 포함 |
| `scripts/merge.py` | 지역 파일 → 통합본 재생성 (`python3 barrier-free/scripts/merge.py`) |
| `all_indicators_verified.csv` | 지표별 원문 검증 결과와 수정값(`value_final`, `year_final`) — **분석에는 이 파일을 사용** |
| `RELIABILITY.md` | 원문 검증 절차·결과·오류율 |
| `VALIDITY.md` | 지표 타당성 검토, 수치 채점 규칙, 세계지도용 글로벌 지표 평가 |
| `reference/` | 공식 원자료: UN CRPD 비준표, Eurostat 고용격차·GALI, World Bank 65+, DDI (`scripts/fetch_reference.py`) |
| `verification/` | 단계별 검증 작업표와 결과 (`scripts/check_sources.py`, `scripts/apply_verification.py`) |
| `rescoring/` | 수치 규칙 + 이중 채점 재산정 결과 (`scripts/score.py`) |
| `perception/` | 자국 인식 vs 해외 인식(설문·한국 SNS·일본어/영어 담론) |

## 데이터 한계 (반드시 확인)
- 수집 환경에서 웹 페이지 원문 열람(WebFetch)이 프록시·DNS 오류로 대부분 차단됐고, 웹 검색 할당량도 중간에 소진됐다. **대부분의 수치는 검색 결과 요약으로만 확인된 값**이다.
- 일부 법령 제정일·CRPD 비준일·의무고용률 등은 사전 지식으로 기재했으며 notes 열에 `확인필요`, `사전지식 기반`, `재인용` 등으로 표시했다.
- 평가 차원이 3개 이하인 국가(동유럽·북유럽·서유럽 소국, 몰타, 멕시코 등)의 종합 등급은 잠정치다. TOUR(관광)는 유럽 대부분에서 미수집.
- 장애 출현율은 국가별 정의가 달라 직접 비교할 수 없다(예: 한국 등록장애인 5.1% vs 호주 21.4% vs 미국 28.7%).
- 러시아는 동유럽·기타 주목국가 두 파일에 모두 있으며, 통합본에는 동유럽 행만 남겼다.
- `all_indicators.csv`에서 EU 전체 등 국가가 아닌 행은 `iso3`가 비어 있다.
