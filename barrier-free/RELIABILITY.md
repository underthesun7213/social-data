# 데이터 신뢰도 리포트 (원문 검증 결과)

`all_indicators.csv`의 지표 405건 전체를 원문 기준으로 검증한 결과다. 행별 결과는 `all_indicators_verified.csv`에 있다.
- `verify_status`, `verify_confidence`: 검증 판정과 신뢰도
- `value_final`, `year_final`: 수정값을 반영한 최종값
- `verify_url`, `verify_note`: 실제로 읽은 원문 주소와 메모

## 1. 검증 절차
| 단계 | 방법 | 대상 | 스크립트/결과 |
|---|---|---|---|
| 0. 공식 원자료 확보 | 공식 API·원표에서 직접 수집 (UN 조약 사무국, Eurostat, World Bank, Disability Data Initiative) | CRPD 비준일, EU 고용격차·장애 출현율, 65세+ 비율 | `scripts/fetch_reference.py` → `reference/` |
| 1. 자동 대조 | 인용 URL 301개를 모두 내려받아, 행의 수치가 원문 텍스트에 있는지 기계적으로 확인 | 405건 | `scripts/check_sources.py` → `verification/source_check.csv` |
| 2. 검색 검증 | 웹 검색 결과로 확인 (네트워크 차단 시기) | 불확실 표시 122건 + 무작위 표본 24건 | `verification/result_[ABC].csv` |
| 3. 원문 검증 | 1단계에서 확인되지 않은 행을 사람이 직접 원문(정부·통계청·법령DB·운영사)과 대조. 인용 링크가 죽었으면 공식 원문을 새로 찾음 | 223건 | `verification/result2_[1-4].csv` |
| 4. 반영 | 3단계 > 1단계 > 2단계 우선순위로 행별 최종 판정 | 405건 | `scripts/apply_verification.py` |

## 3. 오류율
- **무작위 표본(검색 단계, n=24):** 처음부터 '확인됨'으로 들어온 행 중 3건이 틀렸다(12.5%). 이탈리아 고용격차, 브라질 고용률, 미국 규정 조항이다.
- **원문 단계 기준:** 처음 수집 시 불확실 표시가 없던 행 283건 중 10건이 수정됐다(3.5%). 자동 대조로 끝나지 않고 사람이 직접 확인한 146건만 기준으로 하면 약 7%다.
- **불확실 표시 행(122건):** 10건(8%) 수정, 7건 미확인·불일치로 남았다.
- **해석:** 처음 수집된 수치는 대략 **10건 중 1건꼴로 값·연도·출처 중 하나가 틀려 있었다.** 현재 `value_final`은 그 오류를 반영한 값이다.

## 5. 아직 남은 약점
- **'원문확인(자동)' 182건은 숫자가 페이지에 있다는 뜻일 뿐이다.** 같은 페이지의 다른 맥락(연도·하위집단)일 가능성이 있다. 신뢰도는 '중'으로 표시했다.
- **미확인 14건 (지도·등급에서 제외 권고):**
  - 사우디 출현율 7.1%, Mowaamah 150곳
  - 서울·울산 저상버스 비율
  - 미국 BLS 16–64세 고용률, KFF 주별 대기자 수
  - 인도 1,671개 건물, 멕시코시티 메트로
  - 호주 인권위 진정 건수
  - 몰타 고용 쿼터 준수 기업 수 등
- **차단된 원문:**
  - BLS·CDC 웹, TfL, MTA, OHCHR, EUR-Lex, Légifrance, 국토부, 법제처, KOSIS
  - 일부는 공식 API(BLS API, data.cdc.gov, MTA open data, Fedlex SPARQL, EU Cellar)나 다른 공식 사본으로 우회했다.
- **최신성:** 원문을 확인하는 과정에서 값이 이미 바뀐 사례가 있었다.
  - NSW 무장애역 72.03% → 72.32%
  - 미국 Section 503의 7% 목표는 2026년 9월 삭제
  - 한국 키오스크 의무는 2025년 11월 완화
- **정확도와 비교 가능성은 별개다.** 값이 정확해도 국가 간 비교가 타당한지는 다른 문제이므로 `VALIDITY.md`와 함께 읽어야 한다.

## 6. 세계지도 사용 판단
- **바로 사용 가능 (공식 API 원자료, 검증 불필요 수준):**
  - `reference/un_crpd_status.csv`: 196개 참여국, 선택의정서 포함
  - `reference/eurostat_employment_gap.csv`: EU·EEA
  - `reference/ddi_estimates.csv`: 65개국. 대부분 저·중소득국이고 조사 연도가 API에 없음
- **사례 패널로 사용 가능:** `all_indicators_verified.csv`에서 원문확인·원문수정 행
- **아직 사용 불가:** 기존 상/중/하 종합 등급. 이중 채점으로 재산정 중이며 결과는 `rescoring/`에 들어간다.
