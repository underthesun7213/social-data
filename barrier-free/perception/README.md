# 자국 인식 vs 해외 인식: 배리어 프리의 동상이몽과 공통의견

세 갈래 조사를 하나로 합친 요약이다. 세부 근거는 각 보고서에 있다.

| 파일 | 내용 | 규모 |
|---|---|---|
| `surveys.md` / `surveys.csv` | 국가 설문(유로바로미터 535, 일본 내각부, 한국 장애인실태조사 등), 각국 CRPD 국가보고서 vs UN 위원회 최종견해, 해외 접근성 순위 | 15개국, 72개 수치 |

**용어**
- **순긍정:** 긍정 비율에서 부정 비율을 뺀 값이다. 한국 SNS는 −1~+1 척도, 일본어·영어는 %p 척도로 계산했다.
- **실측:** 원문 검증을 거친 `all_indicators_verified.csv`의 값이다.

## 2. 동상이몽: 같은 대상, 다른 믿음
1. **평가 축이 다르다.**
   - 외국인(여행자)은 "여행할 수 있는가", 곧 교통·숙소로 평가한다.
   - 자국민은 "살 수 있는가", 곧 태도·제도·교육으로 평가한다.
   - 일본은 자국 −16, 영어권 +22로 38포인트 차이가 난다. 해외 평판이 좋은 나라일수록 이 격차가 커진다.
2. **같은 제도, 정반대 해석.**
   - 일본 역무원의 사전연락·동행 지원은 일본 안에서 '승차거부·わがまま(제멋대로)' 논쟁거리다(관련 39건 중 38건 부정).
   - 영어권과 한국 SNS에서는 '감동적인 환대'로 소비된다.
   - 한국 SNS의 일본 우위 근거도 대부분 시설이 아니라 이 '사람의 응대'였다.
3. **상상된 외부 시선.**
   - 일본어 유튜브의 「海外の反応」(해외 반응) 장르 47건은 100% 긍정이지만, 실제 영어 콘텐츠의 71%는 중립적인 실용 정보다.
   - 반대로 일본어권의 "서구는 사람들이 알아서 돕는다"는 이미지는 영어권 자신의 담론에서는 확인되지 않는다.
   - 외부 시선은 자국 사회를 비추는 거울로 만들어지는 경우가 많다.
4. **북유럽·스페인 역설.**
   - EU 시상(외부)은 스웨덴과 스페인을 모범국으로 본다.
   - 그러나 스웨덴 시민의 차별 인식은 EU 상위권이고 계속 오르고 있다. 스페인은 UN이 건물 접근률 0.6%를 지적했다.
   - **"차별 인식이 높다"는 것이 "더 차별적"이라는 뜻은 아니다.** 권리의식이 높을수록 응답이 올라간다.
5. **한국 시위의 두 프레임.**
   - 일본어권은 「やり方に問題」, 곧 질서의 문제로 본다.
   - 영어권은 "still no equal rights", 곧 권리의 문제로 본다.
   - 한국 SNS에는 두 프레임이 모두 있다. "한국 지하철은 세계 최고, 전장연은 선동"이라는 반대 프레임은 시위 비판에 쓰인다.
6. **자국 도시 편향.** '세계 접근성 도시' 목록(Valuable 500)에서 응답자는 예외 없이 자국 도시를 1위로 꼽았다. 순수한 해외 평가로 든 도시는 싱가포르, 암스테르담, 파리뿐이다.

## 3. 공통의견: 거의 모든 관점이 동의하는 것
1. **파리 지하철은 휠체어로 사실상 이용할 수 없다.** 한국어·일본어·영어 모두 부정적이고, 실측(3%, 29개 역)과도 맞는다.
2. **도쿄·싱가포르의 대중교통 설비는 우수하다.** 담론과 실측이 일치한다.
3. **"기준은 있지만 모니터링·제재가 없다."** 대부분의 UN 최종견해에 나오고(사우디, UAE, 이탈리아, 영국, 캐나다, 스웨덴, 호주), 자국 시민의 높은 차별 인식과도 맞는다.
4. **물리적 접근성은 나아졌지만 고용·교육은 정체돼 있다.** 고용격차는 측정 가능한 32개국 대부분에서 15%p 이상이다(`rescoring/`).
5. **일본의 약점은 숙소와 지방이다.** 영어권은 휠체어용 샤워실이 드물다고 하고, 일본어권은 무인역 문제를 지적한다. 실측(호텔 휠체어 객실 의무 1%)과도 맞는다.

## 4. 담론이 놓치는 것 (실측과의 괴리)
| 담론에 없거나 거의 없는 사실 | 실측 |
|---|---|
| 한국 지하철 엘리베이터 동선은 일본과 대등하다 | 서울 전 역 완료(2025) vs 일본 94.3% |
| 한국의 실제 약점은 버스다 | 저상버스 44.4% vs 일본 72.1% |
| 한국이 법·디지털 의무에서 일본을 앞선다 | 장애인차별금지법(2008 시행), 민간 웹·키오스크 의무 / 일본 민간 합리적 배려는 2024년 |
| 호주의 대중교통 기한 미달 | 멜버른 트램 18% |
| 미국은 CRPD 미비준국이다 | UN 조약 원표 |
| 영국은 UN에서 '중대·체계적 위반' 판정을 받았다 | CRPD 조사(2016) |
| 일본 분리교육에 대한 UN 권고 | 영어권 담론에서 언급 비중 1% |
| 파리 버스는 100% 접근 가능하다 | 일본어·한국어 담론에 반영되지 않음 |

## 5. 한계
- **수집 범위:** Reddit, X(트위터), 트립어드바이저, 더쿠는 접속이 막혀 수집하지 못했다. 검색엔진의 순위 편향(최신 글 우선)도 남아 있다.
- **논조 판정 정확도:** 무작위 50건을 직접 확인한 결과, 한국어 규칙은 약 70%(부정 쪽으로 과대 추정), 일본어·영어 규칙은 88%(κ≈0.77)였다.
- **표본 쏠림:**
  - 영어권 일본 항목의 67%가 한 사이트에서 나왔다. 그 사이트를 빼면 순긍정이 +22에서 +8로 떨어진다.
  - 일본어권이 다른 나라를 다룬 표본은 나라별 20건 미만이라 정량화하지 않았다.
- **설문 비교:** 국가 설문은 문항이 서로 달라 순위 비교에 쓸 수 없다. 유로바로미터는 EU 회원국에만 해당한다.
- **개인정보:** 개인 블로그(네이버 블로그·카페, 하테나 블로그, note 등) 주소는 개인 ID가 들어 있어 해시값으로 바꿔 저장했다. 원 수집 HTML은 저장소에 올리지 않았다.
