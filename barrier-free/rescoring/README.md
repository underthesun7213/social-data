# 등급 재산정 (수치 규칙 + 이중 채점)

`VALIDITY.md` 4.2–4.3의 채점 규칙으로 47개국을 다시 채점했다. 채점자 A와 B가 서로의 결과와 기존 등급을 보지 않고 독립적으로 채점했으며, 근거는 검증된 지표(`all_indicators_verified.csv`)와 공식 원자료(`reference/`)다. `python3 barrier-free/scripts/score.py`를 실행하면 결과를 다시 만들 수 있다.

| 파일 | 내용 |
|---|---|
| `coding_A.csv`, `coding_B.csv` | 채점자별 항목 값과 근거 |
| `scores_by_coder.csv` | 채점자별 차원 등급과 종합 등급 |
| `consensus.csv` | 두 채점자가 일치한 등급만 남긴 최종본 |

## 1. 채점자 간 일치도 (항목 수준, Krippendorff α)
| 항목 | 둘 다 채점 | 일치 | α | 비고 |
|---|---|---|---|---|
| LAW1–2 (CRPD·선택의정서) | 47 | 47 | 1.00 | UN 원표에서 기계적으로 가져와 당연히 일치 |
| LAW3 (민간 차별금지법·합리적 편의) | 33 | 32 | 0.89 | B만 판정한 국가 7곳 |
| LAW4–6 | 41–47 | 전부 | 1.00 | |
| BUILT1 | 41 | 41 | 1.00 | |
| BUILT2–4 (개보수 의무·감사·준수율) | 2–8 | 전부 | – | **대부분 판정 불가** |
| DIGI1 (공공 WCAG 의무) | 31 | 29 | 0.47 | 가장 낮음 |
| DIGI2–3 | 27–32 | 전부 | – | |
| DIGI4 (준수율 50% 이상) | 0 | – | – | **47개국 모두 자료 없음** |
| TRANS (지하철·버스·철도 수치) | 2–11 | 전부 | 1.00 | 표본이 적음 |
| EMP_GAP (고용격차) | 32 | 32 | 1.00 | 대부분 Eurostat 원표에서 가져옴 |

**해석 주의:** 일치도가 높게 나왔지만 실제 신뢰도보다 부풀려진 수치다.
- 두 채점자는 같은 AI 모델이고, 같은 근거 파일을 읽었다. 사람 두 명이 독립적으로 채점한 것과 같다고 볼 수 없다.
- LAW3·4·5와 DIGI 항목의 상당수가 근거 파일이 아니라 '사전지식'(법률 일반 지식)으로 채점됐다. 두 채점자가 같은 오류를 공유할 수 있다.
- 사람 연구자가 무작위 10개국을 다시 채점해 α를 확인하는 단계가 필요하다.

## 3. 결론
1. **수치 규칙을 엄격하게 적용하면 47개국 중 45개국은 종합 등급을 낼 수 없다.** 기존 상/중/하 종합 등급은 자료가 부족한 상태에서 판단으로 채운 결과였다.
2. **LAW는 변별력이 없다.** 법 조문 기준 체크리스트에서는 47개국 중 33곳이 '상'이다. 법이 있느냐보다 집행되느냐가 차이를 만들기 때문에, 법 조문만으로는 국가가 구분되지 않는다.
3. **BUILT·DIGI는 이행 실태 자료가 거의 없다.** 기존 건물 개보수 이행률과 웹 접근성 준수율을 국가 간 같은 기준으로 공표하는 곳이 드물다. 이것 자체가 각국 정책 모니터링이 약하다는 발견이다.
4. **국가 간 비교에 실제로 쓸 수 있는 산출 지표는 EMP(고용격차) 하나뿐이다.** 32개국에서 같은 정의의 값을 확보했고, 그중 대부분이 Eurostat 국가다.
   - 상: 룩셈부르크, 스위스
   - 하: 벨기에, 불가리아, 아일랜드, 리투아니아, 몰타, 뉴질랜드, 폴란드, 루마니아, 세르비아 등
   - 한국·일본·싱가포르·중동은 같은 정의의 격차 수치가 없어 비어 있다.
5. **세계지도에서는 국가를 종합 등급으로 칠하지 않는다.** 대신 아래처럼 구성한다.
   - **바탕 레이어:** CRPD·선택의정서 비준 상태
   - **산출 레이어:** 고용격차 (Eurostat 및 공식 통계 확보국만)
   - **사례 오버레이:** 우리 47개국. 차원별 원지표를 보여 주고, 종합 등급은 표시하지 않는다.
